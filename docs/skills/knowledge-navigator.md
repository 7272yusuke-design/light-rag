# Knowledge Navigator

LightRAGナレッジベースを活用して、実装提案・技術選定・問題解決を支援するスキル。

## トリガー
- 「〇〇を実装したい」「〇〇の実装方法」
- 「〇〇に使えるライブラリは？」「〇〇の技術選定」
- 「〇〇のコード例を教えて」「〇〇のベストプラクティス」
- 「〇〇でエラーが出る」「〇〇のトラブルシュート」
- 「ナレッジから検索して」「知識ベースで調べて」
- プロジェクト（OpenClaw等）の実装相談全般

## 手順

### Step 1: ナレッジ検索
LightRAG MCP の search_knowledge ツールを使い、関連ナレッジを検索する。
- 技術名・ライブラリ名で検索
- 抽象的な質問は複数クエリに分解
- project引数でプロジェクトフィルタ

### Step 2: 検索結果の評価
- レベル3: コードパターンを直接引用し適応提案
- レベル0-1: 概要ベースで方向性提案 + レベルアップ推奨
- 該当なし: 自身の知識で回答 + 新規投入を提案

### Step 3: クロスナレッジ合成
複数ナレッジが関連する場合、組み合わせて実装プランを提案。

### Step 4: アクション提案
- レベルアップ推奨（レベル0使用時）
- 新規投入提案（ナレッジにない技術）
- VPS検索コマンド提示（詳細検索）

## 重要ルール
- 検索結果があれば必ず活用。自身の知識だけで回答しない
- レベル情報を正直に伝える
- 複数ナレッジは組み合わせを提案
- 投入日が古い場合（6ヶ月以上）は注記
