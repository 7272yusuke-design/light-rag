# Combination Architect

ナレッジベースのL1を組み合わせて、企画提案・設計・ナレッジ投入までを支援。

## トリガー
- 「〇〇を作りたい」「〇〇のアイデアが欲しい」
- 「ナレッジを組み合わせて何か作れない？」
- 「実装したパターンをナレッジに入れたい」
- 「L2/L3ドキュメントを作って」

## Mode A: 企画提案
ナレッジから組み合わせ可能なパーツを検索し、実現可能な企画を3案提示。

## Mode B: 設計
決まった企画に対し、各パーツの役割・接続方法・データフロー・技術課題を設計。

## Mode C: ナレッジ投入
実装完了後、DATA-SCHEMA.mdのL2/L3テンプレートに沿ったドキュメントを生成。

## 重要ルール
- 企画は実在するL1ナレッジに基づく
- レベル0使用時は「レベルアップ推奨」明記
- L2投入はverified以上、L3投入はproduction以上
- experimentalはナレッジに入れない
- 「判明した制約・工夫」を最重要知見として扱う
